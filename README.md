# Cursor Gaze / CursorScrubVideo

Interactive felt character that looks around as you move the mouse.

## Live demo

**https://mhosseinbaghaee-byte.github.io/cursor-scrub-video/**

Move the mouse over the video — the character follows left/right.

## Framer

1. Create a new Code Component in Framer
2. Paste `CursorScrubVideo.tsx`
3. Upload `character-scrub.mp4` to the Video prop

The video is encoded with every frame as a keyframe for smooth scrubbing.
